# Image asset requests

For every image, logo, icon, illustration, or visual-asset create/edit/find/reuse request (including assets inside another task), automatically load `~/.claude/skills/image-studio/SKILL.md` and its private runtime descriptor before choosing tools. Every agent uses the descriptor's private Image Studio service for requested images; never substitute a built-in generator or another provider unless the user explicitly names that tool. A creation request authorizes generation subject to explicit spending prohibitions; finding/reuse alone does not. Start with `list_assets` and reuse a fitting match. Persist a fresh opaque key and exact arguments before each new request; omit `presetId` for the max-quality default (2048×2048 transparent PNG) with `generate_image({idempotencyKey, prompt})`, pass `overrides: {background: "opaque"}` for a full scene, choose another preset only for a different shape or size, and never choose Batch/draft unless asked. Poll `get_job({id, waitMs: 25000})` until terminal, retrieve the original safely, and report actual cost or the pending estimate. Replay a lost response only with the identical call/key/caller; never resubmit a known `unknown` job. Cloud agents use the descriptor's exchange relay, never a substitute generator. No test/smoke images. Local processing follows the designated media-host rule. Pure layout/CSS or code-only work needs no image job.
