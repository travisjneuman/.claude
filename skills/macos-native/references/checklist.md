# macos-native: Checklist

Part of the `macos-native` skill. Overview and the list of other reference files: [SKILL.md](../SKILL.md).

## Checklist

### Mac App Store Submission

- [ ] App Sandbox enabled
- [ ] Hardened Runtime enabled
- [ ] All entitlements justified
- [ ] Privacy descriptions in Info.plist
- [ ] App icon (all sizes)
- [ ] Screenshots for App Store
- [ ] No private API usage

### Best Practices

- [ ] Support keyboard navigation
- [ ] Respect system appearance (dark/light)
- [ ] Support Full Screen
- [ ] Handle window restoration
- [ ] Implement proper undo/redo
- [ ] Support standard keyboard shortcuts
