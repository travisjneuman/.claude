# Image asset requests

For any request to create, edit, find, or reuse an image, logo, icon, illustration, or visual asset (including an asset needed within another task), automatically load `~/.claude/skills/image-studio/SKILL.md` and its private runtime descriptor before choosing tools. Start with `list_assets` and reuse a fitting match. Follow the workflow's confidentiality and durable-job rules; find/reuse does not authorize paid creation. Pure layout/CSS and code-only changes need no image job. Honor explicit user tool choices and all current spending prohibitions.
