# pwa-development: Best Practices

Part of the `pwa-development` skill. Overview and the list of other reference files: [SKILL.md](../SKILL.md).

## Best Practices

### DO:

- Use HTTPS (required)
- Provide offline fallback
- Cache static assets
- Show update notification
- Handle all screen sizes

### DON'T:

- Cache everything forever
- Block app on SW update
- Ignore iOS limitations
- Skip manifest icons
- Forget offline states
